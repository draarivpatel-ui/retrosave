Paused simulation

Each step consumes one recorded input frame at 1/60 second. During replay, stepping consumes the next replay input.

Replay inspector

An RSAVE1 token contains the exact seed, frame count, and input transitions. Inspect it to resimulate the run and compare its final state with the saved reference.


          
FNV-1a detects damaged data. It is not an authentication signature. Reference digests compare results under the same engine version. Recordings are limited to one hour.

Local scores

          
Completed live runs are stored locally as validated RSCORE1 records. Replaying a token does not add a score. Checksums detect corruption and do not prevent deliberate editing.
